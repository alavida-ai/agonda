---
title: workspace list
description: Query across all workspaces — who owns what, what each workspace is for, and how recently it moved.
---

The primary visibility tool. Scans all `workspace.json` files under `workspace/`.

## Usage

```bash
agonda workspace list [filters] [--verbose] [--json]
```

## Output

```
Agonda
2 workspaces

ACTIVE (2)

  barryos-website           Thomas    business  1d ago
    workbench: website-dev
    deliverable: Landing page with lead capture live on agonda.ai

  content-engine            Thomas    internal  new
    workbench: content-creator
    deliverable: Record and package short-form content pipeline experiments

Total 2  |  stale 0  |  business:1  internal:1
```

Use `--verbose` to add tactic and Linear link lines to each workspace entry.

## Filter Flags

All flags are optional and AND-combined:

| Flag | What it filters |
|------|----------------|
| `--status active` | Only active workspaces |
| `--owner Thomas` | Thomas's workspaces |
| `--tactic T2.1` | Linked to this tactic |
| `--workbench website-dev` | Using this workbench |
| `--work-type business` | Business workspaces only |
| `--linear-type issue --linear-id ALA-340` | Linked to this exact issue |
| `--linear-project ALA-142` | Linked to this project (or milestones within it) |
| `--verbose` | Show tactic and Linear metadata in human output |

## Common Queries

```bash
# How much is in flight?
agonda workspace list --status active

# Revenue work vs infrastructure
agonda workspace list --work-type business
agonda workspace list --work-type internal

# Find workspace for a Linear ticket
agonda workspace list --linear-type issue --linear-id ALA-340

# What needs synthesis?
agonda workspace list --status ready-for-synthesis
```
