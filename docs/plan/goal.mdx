---
title: plan goal
description: Add, edit, remove, and list goals in your 12-week plan.
---

Goals are what the team is trying to achieve within a cycle. 1-3 per plan. Each has a lag measure (the result you want) and a target.

## Add a Goal

```bash
agonda plan goal add \
  --id G1 \
  --name "Close 3 paid client engagements" \
  --owner Thomas \
  --lag-measure "Number of signed contracts" \
  --target 3
```

| Flag | Required | Description |
|------|----------|-------------|
| `--id` | Yes | Unique identifier (format: `G{n}`) |
| `--name` | Yes | Goal name |
| `--owner` | Yes | Accountable person |
| `--lag-measure` | Yes | What you're measuring (the outcome) |
| `--target` | Yes | Numeric target |
| `--current` | No | Current progress (defaults to 0) |

Maximum 3 goals per plan. Rejects duplicate IDs.

## Edit a Goal

```bash
agonda plan goal edit G1 --current 1
agonda plan goal edit G1 --target 5 --owner Alex
```

Positional argument is the goal ID. Only provided flags are updated. At least one flag required.

## Remove a Goal

```bash
agonda plan goal remove G1
```

<Warning>
  Warns if tactics reference this goal but proceeds. Orphaned tactics will fail `plan validate`.
</Warning>

## List Goals

```bash
agonda plan goal list
agonda plan goal list --json
```

Lists all goals in the plan. No filtering needed — there are at most 3.
