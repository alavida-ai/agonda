The single most useful command. Shows your full plan with computed state.

## Usage

```bash
agonda plan view [--json]
```

## Output

```

Week 1 of 12 • Cycle 2

  G1   Close 3 paid client engagements  Thomas   0/3
  G2   Ship 5 public workbenches to GitHub with landing pa…  Alex     0/5
  G3   Produce 60 pieces of short-form content  Thomas   0/60

Due This Week (9)
  T1.1   Schedule 3 discovery calls per week with ICP prospects
         Thomas  weekly
  T1.4   Run rehearsal sales call with BarryOS founders (Morris + Ward)
         Thomas  wk 1

Overdue (0)
  Nothing overdue.
```

## How It Works

- **Current week** is computed from cycle dates and today's date — never stored
- **Overdue** = deliverable where `due_week < current_week` and `completed` is not `true`
- **Workspace paths** appear next to tactics when a workspace's `tactic` field matches
- Human output is branded and optimized for scanning; use `--json` for full structured data
