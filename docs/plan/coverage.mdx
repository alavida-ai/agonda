---
title: plan coverage
description: See which plan tactics are backed by registered workspaces and which commitments still have no governed execution.
---

Shows plan tactics grouped by goal, annotated with registered workspace coverage.

## Usage

```bash
agonda plan coverage [--goal <id>] [--uncovered-only] [--json]
```

## What It Answers

- Which tactics already have linked workspaces?
- Which commitments have no governed execution yet?
- How much of the current plan is covered by registered workspaces?

Coverage is strict by design: only registered workspaces with a matching `tactic` field count. Raw directories on disk do not satisfy coverage.

## Filter Flags

| Flag | What it does |
|------|--------------|
| `--goal G1` | Show one goal only |
| `--uncovered-only` | Show only tactics with no linked workspace |
